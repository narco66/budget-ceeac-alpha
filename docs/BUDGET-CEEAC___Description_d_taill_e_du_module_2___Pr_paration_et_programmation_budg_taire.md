# BUDGET-CEEAC  
## MODULE 2 — PRÉPARATION ET PROGRAMMATION BUDGÉTAIRE

---

## 1. Présentation générale

Le module **Préparation et programmation budgétaire** constitue le point d’entrée du cycle budgétaire de BUDGET-CEEAC.

Il permet d’organiser, de coordonner et de sécuriser l’ensemble des travaux précédant l’adoption et l’ouverture du Budget annuel de la Commission de la CEEAC.

Il assure la transformation progressive :

**Orientations institutionnelles → Planification stratégique → Programmation pluriannuelle → PAP → Propositions budgétaires → Arbitrages → Consolidation → Projet de Budget → Budget validé**

Le module doit assurer une parfaite continuité entre :

- la stratégie de la Commission ;
- la Gestion Axée sur les Résultats — GAR/RBM ;
- le Plan Annuel de Performance — PAP ;
- les besoins de fonctionnement ;
- les investissements ;
- les financements CEEAC ;
- les financements des Partenaires Techniques et Financiers — PTF ;
- la nomenclature budgétaire ;
- les crédits autorisés ;
- et, ultérieurement, l’exécution de la dépense.

---

# 2. Principe fondamental de BUDGET-CEEAC

BUDGET-CEEAC doit respecter le principe suivant :

> **Un exercice budgétaire correspond à un Budget unique.**

Le **PAP ne constitue pas un budget distinct**.

Il représente la composante du Budget consacrée aux actions, activités, tâches et investissements programmés suivant la logique de Gestion Axée sur les Résultats.

Le Budget de l’exercice comprend donc notamment :

### Budget de fonctionnement

Dépenses récurrentes nécessaires au fonctionnement des structures de la Commission.

### Budget lié au PAP

Dépenses liées aux programmes, projets, activités et investissements inscrits dans la programmation annuelle de performance.

Toute la conception du module doit respecter cette unicité du Budget.

---

# 3. Finalités du module

Le module doit permettre à la Commission de :

- préparer son Budget annuel ;
- organiser les campagnes budgétaires ;
- traduire les priorités institutionnelles en allocations budgétaires ;
- construire la programmation pluriannuelle ;
- élaborer le PAP ;
- recueillir les besoins des structures ;
- fixer des plafonds budgétaires ;
- estimer les coûts ;
- hiérarchiser les priorités ;
- organiser les arbitrages ;
- identifier les financements ;
- consolider les propositions ;
- vérifier l’équilibre entre ressources et besoins ;
- produire le projet de Budget ;
- préparer les éléments destinés à l’approbation ;
- assurer la traçabilité complète du processus.

# 5. Gestion des campagnes budgétaires

La préparation budgétaire doit être organisée autour d’une **campagne budgétaire**.

Une campagne correspond au processus officiel de préparation du Budget d’un exercice donné.

Exemple :

**Campagne de préparation du Budget 2027**

Chaque campagne possède notamment :

- exercice concerné ;
- code ;
- libellé ;
- date d’ouverture ;
- date limite de saisie ;
- date limite de soumission ;
- période de consolidation ;
- période d’arbitrage ;
- date prévue d’approbation ;
- statut ;
- responsable ;
- instructions ;
- observations.

---

# 6. Statuts d’une campagne budgétaire

Les statuts doivent être paramétrables.

Exemple :

**Brouillon → Planifiée → Ouverte → Collecte des propositions → Consolidation → Arbitrage → Validation → Approbation → Clôturée → Archivée**

Le changement de statut doit être contrôlé et journalisé.

# 10. Intégration de la Gestion Axée sur les Résultats

Le module doit exploiter le référentiel RBM/GAR de BUDGET-CEEAC.

La chaîne retenue est :

**Pilier → Axe → Produit → Sous-produit → Activité → Tâche**

Chaque dépense relevant du PAP doit pouvoir être reliée à un niveau approprié de cette chaîne.

Exemple :

**Pilier**  
→ Intégration économique régionale

**Axe**  
→ Facilitation des échanges

**Produit**  
→ Dispositifs régionaux harmonisés

**Sous-produit**  
→ Cadre opérationnel mis à jour

**Activité**  
→ Réaliser une mission régionale

**Tâche**  
→ Organiser l’atelier technique

# 20. Contrôle de cohérence du PAP

# 21. Estimation des coûts

Chaque proposition peut être estimée à partir :

**Quantité × Coût unitaire = Montant**

Le système doit également permettre :

- coût forfaitaire ;
- coût détaillé ;
- coût par composante ;
- coût pluriannuel ;
- estimation en devises ;
- conversion en XAF.

- PTF ;
- financement mixte ;
- autres sources autorisées.

- organisme ;

- taux de change ;
- part financée ;
- statut ;
- convention ;
- période.

---

# 23. Répartition CEEAC / PTF

Pour une dépense cofinancée :

**Montant total = Part CEEAC + Part PTF**

Exemple :

Montant : 100 000 000 XAF

CEEAC : 30 000 000 XAF  
PTF : 70 000 000 XAF

Cette répartition doit être conservée jusqu’à l’exécution.

# 27. Score de priorité

Le système peut calculer :

**Score global = Σ (critère × pondération)**

Cela facilite l’arbitrage.

# 69. Règles métier essentielles

### RB-PPB-01
Une campagne est liée à un exercice unique.

### RB-PPB-02
Un exercice ne doit pas posséder plusieurs Budgets officiels actifs.

### RB-PPB-03
Le PAP appartient au Budget de l’exercice.

### RB-PPB-04
Toute proposition PAP doit être rattachée à la chaîne RBM.

### RB-PPB-05
Une proposition ne peut être consolidée sans validation requise.

### RB-PPB-06
Une proposition ne peut dépasser son plafond sans dérogation autorisée.

### RB-PPB-07
Tout arbitrage doit être motivé.

### RB-PPB-08
Les valeurs antérieures doivent être historisées.

### RB-PPB-09
Le financement total doit correspondre au montant de la proposition.

### RB-PPB-10
Part CEEAC + Part PTF = Montant financé.

### RB-PPB-11
Une proposition approuvée ne peut être supprimée physiquement.

### RB-PPB-12
Toute modification après validation doit être tracée.

### RB-PPB-13
Une campagne clôturée est verrouillée.

# 80. Principe directeur final

Le module **Préparation et programmation budgétaire** doit garantir qu’aucun crédit ne soit intégré au Budget de la Commission sans pouvoir répondre aux questions suivantes :

- Pourquoi cette dépense est-elle programmée ?
- Quelle structure l’a proposée ?
- À quel objectif institutionnel répond-elle ?
- Relève-t-elle du PAP ou du fonctionnement ?
- À quel élément RBM est-elle rattachée ?
- Quel est son coût ?
- Comment est-elle financée ?
- Quel plafond lui est applicable ?
- Qui l’a validée ?
- A-t-elle fait l’objet d’un arbitrage ?
- Quel montant a finalement été retenu ?
- Quelle est l’origine de la ligne budgétaire créée ?

Le module doit ainsi constituer la **charnière officielle entre stratégie, programmation, performance et Budget** dans BUDGET-CEEAC.
